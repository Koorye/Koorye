## 研究简介

- **大规模机器人操作数据** — 第一人称与双臂数据集、意图感知采集、层次化标注。
- **具身基础模型** — 视觉-语言-动作模型适配、测试时推理与空间推理。
- **视觉语言模型迁移** — 提示调优、参数高效学习与对比学习。

当前工作围绕 **HumanCOIN**（12,500 小时第一人称操作数据、38 个场景类别、30 家机构，包含注视/表面肌电/脑电三层意图信号）与 **RoboCOIN**（20 家机构、15 个本体、18 万+ 演示数据）。
